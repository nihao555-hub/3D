# 主流笔式旋转纹身机 · 工厂打样包

对标 Cheyenne Hawk Pen / FK Irons Flux 的有线 RCA 笔形 OEM。源码：`rotary-tattoo-pen.scad`。

在 [智造3D](https://zhizao3d.vercel.app) 用**参数化**模式打开该文件（或把源码贴进对话），可拖滑块改尺寸后导出 STL / SCAD / DXF。

## 导出零件

把 `print_part` 依次改成下面的值，各出一份 STL（装配预览用 `assembly`）：

| print_part       | 零件       | 工艺建议                                     |
| ---------------- | ---------- | -------------------------------------------- |
| `housing_left`   | 左壳体     | FDM PETG/ABS，0.2 层高，4 圈墙，RCA 朝下竖打 |
| `housing_right`  | 右壳体     | 同上                                         |
| `grip_sleeve`    | 滚花握把套 | TPU 95A 或 PETG                              |
| `cartridge_nose` | 卡口鼻锥   | PETG，尖端朝上，支撑尽量少                   |
| `rca_cap`        | 尾盖       | PETG                                         |
| `cam`            | 偏心凸轮   | 尼龙 / POM，或 CNC 黄铜                      |
| `needle_bar`     | 针杆       | 样机可 PETG；量产 304 不锈钢                 |
| `cable_clip`     | 线夹       | PETG                                         |

剖切：`cutaway=true` 切掉右壳，露出电机、凸轮、针杆、弹簧。  
爆炸：`explode>0` 沿轴向拉开。  
视窗：`window_open=true` 握把椭圆窗看见针杆往复。

## 关键尺寸（可滑块）

- 机身长度 132 mm（110–160）
- 握把直径 25 mm（20–32）
- 偏心距 1.5 mm → 针行程 3.0 mm
- 壁厚 1.6 mm
- 滚花节距 1.6 / 深 0.35
- 轴孔比轴大 0.25；M2.5 过孔 2.7；止口间隙 0.15

## 装配顺序

1. 铜套压入左壳前后座。
2. 针杆穿过铜套，套上复位弹簧。
3. 凸轮装电机轴，M2 顶丝锁偏心。
4. 电机落入电机舱，轴上凸轮落入针杆从动槽。
5. PCB 放入槽位，RCA 从尾盖穿入焊接。
6. 右壳合上，4×M2.5 沉头锁紧。
7. 鼻锥旋入/卡入，尾盖到位，线夹卡住硅胶 RCA 线。
8. 插上卡式针头，通电试行程。
